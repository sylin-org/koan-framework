# Explanation shapes

Choose the smallest shape that makes the answer clear.

## Direct "why?" answer

1. **Answer:** one sentence.
2. **Observed:** the decisive local evidence.
3. **Inference:** how the evidence explains the result.
4. **Unknown:** only material missing evidence.
5. **Next check:** one read-only check or a handoff to `koan` or `koan-upgrade`.

## Application flow

Use a compact flow when behavior crosses several owners:

```text
doorway -> application operation or Entity -> capability route -> provider -> result or failure
```

Add authorization, tenancy, jobs, events, or storage only when they participate.

## Capability answer

Report the local dependency evidence, configuration intent, effective selection evidence, and observed behavior. State explicit non-claims. A referenced dependency alone does not prove selection, health, or behavior.

Lead with meaning. Use file and type names as evidence, not as the story.
