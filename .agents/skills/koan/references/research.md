# Current external seams

Use current primary sources when a Koan decision depends on an external provider, protocol, standard, security rule, platform, or cited resource that can change.

## Keep evidence roles separate

- Use current Koan docs, public types, source, focused tests, and application facts for Koan behavior.
- Use normative specifications or official vendor documentation for external behavior.
- Use issues and practitioner reports only for observed operational pain or sentiment.
- Label inference as inference.

Research the decision, not the entire ecosystem. Verify dates and the effective API or protocol surface, then translate the result into Koan's grammar:

1. the capability reference that expresses availability;
2. the Entity or application operation that owns the behavior;
3. explicit provider, source, security, and failure policy;
4. behavior, composition, and corrective proof.

Do not copy another framework's registration ceremony into a Koan app. Cite the exact supporting source near volatile claims and end with the smallest Koan-native recommendation plus the evidence that would change it.
