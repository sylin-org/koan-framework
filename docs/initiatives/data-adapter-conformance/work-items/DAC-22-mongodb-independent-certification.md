# DAC-22 — Independently certify MongoDB as a gold reference

| Field | Value |
|---|---|
| Phase / kind | gold / certification |
| Depends on | DAC-23 |
| Unlocks | DAC-30 (with DAC-12) |
| Primer scope | complete frozen MongoDB manifest |
| Production writes | forbidden |
| Owner | Independent certification |

## Meaningful outcome

“Document gold reference” is backed by fresh provider, topology, permission, fault, and resource evidence.

## Required work

1. Reproduce DAC-23's integrated checkpoint and dynamically re-inventory surfaces, claims, registrations, types,
   execution paths, and retirement absence.
2. Run strict Forge and every applicable MongoDB cell against every topology and least-privilege role in the manifest.
3. Re-run native commands/dispatch counts, faults and commit outcomes, cancellation, pool/resource lifecycle,
   restart/durability, soak, bounds, and provider-relative cold/warm performance evidence.
4. Reconcile examples, facts, health, diagnostics, docs, and product claim inputs to executable topology-sensitive truth.
5. Adversarially review policy bypass, message classification, swallowed driver errors, static topology overclaim,
   hidden client fallback, duplicate Document ownership, unbounded state, copied structure, bridges, and dead helpers.
6. Change evidence/truth only. A failure returns as a contract-linked black-box case to DAC-21; DAC-24, DAC-23, and
   both certifications rerun. Never repair production in certification or restore retired code.

## Definition of done

- [ ] Independent packet verdict PASS with zero Observed RED/DEFER.
- [ ] Source identity exactly matches DAC-12's DAC-23 checkpoint.
- [ ] Every decline and unavailable topology feature has corrective negative proof.
- [ ] Empty-root, architecture, retirement-absence, and one-execution-path verdicts pass.
- [ ] MongoDB is recorded as earned document gold; public promotion remains DAC-90 work.

## Stop conditions

Any production edit, skipped required topology, unexplained regression, missing permission proof, legacy/dead/bridge
path, architecture concern, or packet mismatch blocks certification.
