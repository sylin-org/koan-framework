# DAC-09 — Independently certify the Koan.Data framework surface

| Field | Value |
|---|---|
| Phase / kind | foundation / certification |
| Depends on | DAC-08 |
| Unlocks | DAC-10 and DAC-20 |
| Primer scope | every Framework-owned row from DAC-01 |
| Production writes | forbidden |
| Owner | Independent certification |

## Meaningful outcome

SQLite and MongoDB begin from a genuinely shared Data contract rather than being asked to compensate for unfinished
Framework behavior.

## Required work

1. Use a fresh session/reviewer identity. Reproduce the sealed source checkpoint in a disposable clean worktree and
   rerun the DAC-01 dynamic surface inventory.
2. Regenerate the framework claim/cell matrix and execute every Framework-owned row through instrumented test doubles,
   native spies, and real `AddKoan()` hosts as appropriate.
3. Confirm target public examples compile and policy/failure/receipt behavior cannot be bypassed through Direct,
   instructions, transactions, initialization, health, or provider extensions.
4. Confirm every provider-dependent row has a narrow Family/Adapter seam and no Framework implementation is copied
   into a connector.
5. Run strict Forge structural validation, focused Data suites, full solution build, docs/code-example checks, and an
   adversarial architecture/security/performance review.
6. Prove every contract selected for SQLite or MongoDB has a compile-ready Framework plus Relational/Document Family
   seam. Provider LIVE evidence remains pending, but a missing shared seam cannot be delegated to a greenfield adapter.
7. Freeze the framework packet. If RED, generate bounded Framework/Family remediation cards and BLOCK gold harvests.

## Verification

- No production files change.
- Required evidence references reproduce from a clean test invocation.
- All Framework-owned rows aggregate PASS; provider LIVE rows remain explicitly pending for gold harvests rather than
  being marked green by a fake.
- A second reviewer searches for adapter-local policy, result materialization, readiness, or mapping copies.

## Definition of done

- [ ] Framework packet is green and signed by an independent certifier.
- [ ] Strict Forge has no missing/duplicate/unmapped IDs.
- [ ] Gold cards receive complete shared authoring contracts, exact Adapter rows, and provider evidence requirements.

## Stop conditions

Any Framework RED/DEFER blocks DAC-10 and DAC-20. Certification does not fix it in place.
