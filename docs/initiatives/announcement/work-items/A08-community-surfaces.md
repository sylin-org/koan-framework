# A08 — Community surfaces

- Tranche: `T2 — Launch`
- Status: `draft`
- Depends on: none (must close before A09)
- Unlocks: A09
- Owner: maintainer

## Meaningful outcome

The places newcomers land are live and honest before the first post: GitHub Discussions enabled
with purposeful categories (Q&A, show-and-tell, defect reports), `SUPPORT.md` updated to route
there, the contribution onramp from `CONTRIBUTING.md` verified to make sense to an outsider, and
a Discord only if the maintainer commits to staffing it — an empty Discord is worse than none.

## Why now

For a solo-maintained framework the community surface is the durability answer to the bus-factor
question every launch will ask. A launch that lands on no community surface converts attention
into nothing.

## Acceptance criteria

- [ ] Discussions live with categories; `SUPPORT.md` updated and merged.
- [ ] First-issue guidance in `CONTRIBUTING.md` verified against the current tree.
- [ ] Discord decision (yes/no) recorded with its staffing commitment.
