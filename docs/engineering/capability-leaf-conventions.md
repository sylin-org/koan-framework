# Capability leaf conventions

Every capability leaf in `docs/capabilities/` follows the same format. LLMs read these leaves as
execution interfaces — the format is designed for cold consumption, not human browsing.

## Required structure

```markdown
---
type: REFERENCE
domain: <domain>
title: "<Human title>"
audience: [ai-agents, developers]
status: current
last_updated: <date>
framework_version: v1.0.0
validation:
  date_last_tested: <date>
  status: passed | not-yet-tested
  scope: <exactly what was tested and how>
---

# <Human title>

<One-sentence promise.>

## You need

| Piece | Package | Note |
|---|---|---|
| ... | exact package ID | ... |

## The constraint box

> **The constraint:** <What the capability does NOT do. What the application owns. The
> failure mode when the constraint is violated.>

## <Usage sections with compilable samples>

## Do not, at this level

- <Anti-patterns specific to this capability>

## Read next

- <Links to related capability nodes>
```

## Sample requirements (the #1 blind-run killer)

- **Every sample states its complete using-block**, labeled per symbol:
  `using Koan.Core; // AddKoan()`
- **No ellipsis or pseudocode** in capability leaves — if a sample is shape-only, move it to
  a guide and link. Capability-leaf samples must compile.
- **First parameter names stated** when a method has non-obvious parameters:
  `Canonize(configure: o => ...)` not `Canonize(o => ...)` (first param is `origin: string`).
- **Layer-complete "You need" tables**: name every layer (AI connector + vector store + data
  store), and quote the exact error the reader sees when a layer is missing.

## Naming laws (apply to all new surfaces)

- **Hook grammar:** base form intervenes, past participle observes. `OnIntake` mutates;
  `OnCommitted` watches.
- **Segment grammar on gateway namespaces:** phases are proper nouns (`Intake`, `Matching`);
  reason categories are past participles (`Stalled`, `Refused`). A plural noun mid-chain
  parses as an owner and is rejected.
- **Async by nature:** methods returning `Task`/`IAsyncEnumerable` keep their plain name —
  the `Async` suffix is never used on Koan surfaces.

## Lint

The snippet lint (`scripts/lint-capability-snippets.ps1`) compiles every block classified as
"compilable" in `snippets.manifest.json`. The manifest is generated by an LLM classification
pass (codex): judgment to the LLM, verification to the compiler. Re-run the classifier after
adding new leaves; re-run the lint after any sample edit.

## Validation status: what it means for the reader

The `validation.status` frontmatter field calibrates how carefully the agent should proceed:

| Status | Meaning | Agent behavior |
|---|---|---|
| `passed` | cold-executed against published packages | proceed normally |
| `not-yet-tested` | the surface may have drifted; no cold run has proven it | be extra skeptical; report gaps; prefer alternative leaves when available |

The `scope` line names exactly what was tested and on which package versions — the *floor*.
Versions older than the floor are unsupported; newer patches are assumed compatible.
